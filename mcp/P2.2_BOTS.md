# P2.2 Deathmatch + Local Bots

P2.2 adds source-free deathmatch generation, deterministic fairness analysis and a single-browser local multiplayer bot runtime on top of P2.1.

## Supported modes

- **1 human + 3 bots**: Player 1 uses the normal keyboard/mouse path. Player 2–4 are controlled by local bot policies.
- **4 bots**: repeatable automated balance/runtime trials.
- Remote browser-to-browser networking is intentionally deferred to P3.0.

The bot runtime uses real LinuxDOOM `players[0..3]` slots and independent `ticcmd` overrides. It does not fake bots as monsters.

## Difficulty profiles

Each bot can use a different preset:

- `easy`
- `normal`
- `hard`
- `nightmare`

Difficulty changes actual control quality rather than player HP. Profiles vary reaction interval, aim tolerance, turning, forward/strafe movement, aggression and dodge behavior.

Example 1-human/3-bot assignment:

```text
Player 1: human
Player 2: easy
Player 3: hard
Player 4: nightmare
```

## MCP

The default P2.2 MCP server is:

```powershell
cd mcp
npm start
```

Key tools include:

- `doom_create_deathmatch_arena`
- `doom_evaluate_deathmatch_fairness`
- `doom_compare_deathmatch_fairness`
- `doom_get_bot_skill_profiles`
- `doom_run_local_bot_deathmatch`
- `doom_prepare_human_bot_arena`

`doom_prepare_human_bot_arena` validates an exported arena and returns a localhost launch URL for Player 1 + three live bots.

## Browser launch

The live scheduler accepts URL parameters:

```text
?p22Bots=easy,normal,hard&p22Map=E1M1
```

When loading an exported PWAD through the MCP bridge the full URL has the form:

```text
http://127.0.0.1:3777/?wad=<candidate>.wad&p22Bots=easy,normal,hard&p22Map=E1M1
```

Click **CLICK TO START**. The launcher starts local deathmatch with four real player slots. Slot 0 remains human-controlled; slots 1–3 are owned by the live bot scheduler.

Runtime inspection/change from the browser console:

```js
DoomLocalBots.status()
DoomLocalBots.setSkill(1, 'nightmare') // Player 2
DoomLocalBots.setSkill(2, 'easy')      // Player 3
DoomLocalBots.setSkill(3, 'hard')      // Player 4
```

## Acceptance gates

P2.2 CI retains P0→P2.1 regressions and additionally verifies:

1. balanced source-free deathmatch generation and fairness scoring;
2. bot-capable LinuxDOOM/Emscripten build;
3. a four-player all-bot match where all players move/attack and damage or frags occur;
4. an interactive Player 1 + three-bot browser run where Player 1 receives normal keyboard input and receives **no** bot ticcmd override while Players 2–4 make bot decisions.

The P2.2 branch and PR are development checkpoints and must not be merged without explicit approval.
