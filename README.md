# Web DOOM

Original Linux DOOM running in the browser via WebAssembly.

- No iframe
- `doom.wasm` is downloaded during GitHub Actions deployment and served locally by GitHub Pages
- Based on the original id Software DOOM source port by Cornelius Diekmann
- Keyboard: Arrow keys, Ctrl, Space, Shift, 1-7, Esc

Live URL after GitHub Pages is enabled/configured for Actions:

`https://pavy23.github.io/web-doom/`

## Source provenance

- Original DOOM source: https://github.com/id-Software/DOOM
- WebAssembly port: https://github.com/diekmann/wasm-fizzbuzz/tree/main/doom
